# تطبيق الدردشة الصوتية

تطبيق دردشة صوتية مباشرة يدعم الاتصال الصوتي والرسائل النصية بين المستخدمين في الوقت الفعلي.

## الميزات

- 🎤 **دردشة صوتية مباشرة**: اتصال صوتي عالي الجودة بين المستخدمين
- 💬 **رسائل نصية**: إرسال واستقبال الرسائل النصية
- 🏠 **نظام الغرف**: إنشاء والانضمام إلى غرف دردشة مختلفة
- 👥 **إدارة المستخدمين**: عرض المستخدمين المتصلين في كل غرفة
- 🔊 **تحكم صوتي**: تشغيل/إيقاف الميكروفون والسماعات
- 📱 **تصميم متجاوب**: يعمل على جميع الأجهزة والشاشات
- 🌐 **واجهة عربية**: دعم كامل للغة العربية

## التقنيات المستخدمة

- **Backend**: Node.js, Express.js, Socket.io
- **Frontend**: HTML5, CSS3, JavaScript
- **الاتصال الصوتي**: WebRTC
- **الاتصال المباشر**: Socket.io

## التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **تحميل المشروع**:
   ```bash
   git clone <repository-url>
   cd voice-chat-app
   ```

2. **تثبيت التبعيات**:
   ```bash
   npm install
   ```

3. **تشغيل التطبيق**:
   ```bash
   npm start
   ```
   
   أو للتطوير مع إعادة التحميل التلقائي:
   ```bash
   npm run dev
   ```

4. **فتح التطبيق**:
   افتح المتصفح وانتقل إلى: `http://localhost:3000`

## كيفية الاستخدام

### الدخول إلى التطبيق
1. أدخل اسم المستخدم
2. أدخل معرف الغرفة (أو اتركه فارغاً لإنشاء غرفة جديدة)
3. اضغط على "دخول"

### الدردشة الصوتية
- اضغط على أيقونة الميكروفون لتشغيل/إيقاف الميكروفون
- اضغط على أيقونة السماعة لتشغيل/إيقاف الصوت
- شريط مستوى الصوت يعرض قوة الصوت الحالية

### الرسائل النصية
- اكتب رسالتك في الحقل السفلي
- اضغط Enter أو أيقونة الإرسال لإرسال الرسالة

### إدارة الغرف
- يمكن للمستخدمين الانضمام إلى نفس الغرفة باستخدام نفس معرف الغرفة
- قائمة المستخدمين تعرض جميع المتصلين في الغرفة الحالية
- يمكن مغادرة الغرفة في أي وقت
